ABOUT THIS PROJECT

Ideas make campus life better.

This Student Event Proposals Management System is a complete full-stack web application developed for ICT251 Activity 8 at Mulungushi University.

Students can create, view, edit and delete event proposals. Use the submission form to add a proposal, and use the search and status filters to find existing records.

All records are stored in a live cloud database through a Node.js REST API. Changes are shared across devices.
